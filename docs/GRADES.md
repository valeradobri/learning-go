# 🎓 Журнал успеваемости и Code Review

В этом документе фиксируются результаты проверки практических заданий, самостоятельной работы и ответов на контрольные вопросы по каждому занятию.

---

## 📐 Методология и критерии оценивания

Каждое занятие оценивается ментором по **5 ключевым критериям** по 10-балльной шкале (от 0 до 10):

1. **Понимание теории (0–10):** способность объяснить, *почему* код работает именно так, знание внутренних механизмов языка и рантайма.
2. **Знание синтаксиса Go (0–10):** корректность использования ключевых слов, объявлений типов, пакетов и стандартной библиотеки.
3. **Самостоятельное написание кода (0–10):** решение задач без готовых подсказок, глубина проработки логики.
4. **Умение находить и исправлять ошибки (0–10):** реакция на замечания компилятора, успешная отладка и самостоятельное устранение багов.
5. **Понимание идиоматического Go (0–10):** соблюдение общепринятых практик Go (*Effective Go*), читаемость, простота, отсутствие оверинжиниринга.

### Итоговая оценка
Рассчитывается как **среднее арифметическое** пяти критериев:
$$\text{Итоговая оценка} = \frac{\text{Теория} + \text{Синтаксис} + \text{Самостоятельность} + \text{Отладка} + \text{Идиоматика}}{5}$$

### Шкала интерпретации
- **9.0 – 10.0:** 🟢 Тема усвоена великолепно. Полная готовность к следующему материалу.
- **7.0 – 8.9:** 🟡 Хороший результат. Можно двигаться дальше, параллельно закрепив отдельные нюансы на практике.
- **5.0 – 6.9:** 🟠 Требуется дополнительная практика и разбор выявленных пробелов перед переходом дальше.
- **0.0 – 4.9:** 🔴 Тема не усвоена. Повторный разбор теории с альтернативными примерами и новыми практическими заданиями.
