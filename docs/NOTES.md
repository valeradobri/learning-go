# 📝 Персональная база знаний по Go

Данный документ — единая база знаний студента. Разделы заполняются и дополняются по мере реального изучения тем. Материалы вносятся только после прохождения уроков и закрепления на практике.

---

## 1. Фундаментальные концепции и теория

### Урок 1: Устройство Go и компиляция
- **Исходный код (Source Code):** понятный человеку текст инструкций на языке программирования (файлы `.go`).
- **Машинный код:** набор команд из нулей и единиц, которые напрямую исполняются процессором.
- **Компилятор (`go build`):** программа-переводчик, которая проверяет весь исходный код от начала до конца и собирает его в полностью автономный бинарный исполняемый файл (`.exe` на Windows). Для запуска собранного `.exe` компьютеру не нужен установленный Go.
- **Интерпретатор (Python, JS):** читает и выполняет код строка за строкой во время работы программы (медленнее, ошибки типов обнаруживаются только в рантайме).
- **Статическая типизация:** тип каждой переменной (число, строка, булево значение) известен заранее и строго фиксирован. Попытка положить неподходящий тип данных пресекается компилятором ДО запуска программы.

## 2. Шпаргалки по синтаксису и идиомам (Idiomatic Go)

### Анатомия минимальной программы
```go
package main // 1. Пакет main указывает, что это исполняемая программа

import "fmt" // 2. Подключение пакета fmt для ввода/вывода

func main() { // 3. Точка входа в программу (скобка { строго на этой же строке!)
    fmt.Println("Привет, Go!") // 4. Вызов публичной (с заглавной буквы) функции
}
```

### Форматированный вывод (`fmt.Printf`)
- `%s` — строка (`string`).
- `%d` — целое десятичное число (`int`, `digit`).
- `%f` — дробное число с плавающей точкой (`float64`).
- `%T` — тип переданного значения (`Type`).
- `\n` — символ перехода на новую строку (в `Printf` обязателен вручную).

## 3. Подводные камни и частые ошибки новичков

1. **Неиспользуемый импорт — ошибка компиляции:** если подключить пакет через `import "..."` и не вызвать из него ни одной функции, компилятор выдаст ошибку `imported and not used`. Мертвый код в Go запрещен.
2. **Перенос открывающей скобки `{` на новую строку:** компилятор Go на этапе лексического анализа автоматически расставляет точки с запятой `;` в концах строк. Перенос `{` приведет к ошибке синтаксиса `syntax error: unexpected semicolon or newline before {`. Скобка `{` должна быть на одной строке с `func main()`, `if`, `for`.
3. **Регистр первой буквы (видимость / экспорт):**
   - **Заглавная буква** (`fmt.Println`, `MyFunc`) — функция/переменная публичная (экспортируемая), доступна снаружи пакета.
   - **Строчная буква** (`myPrivateFunc`) — функция приватная, доступна только внутри своего пакета.

## 4. Справочник команд Go Tooling

- `go run <file.go>` — быстрая компиляция во временную память и немедленный запуск. Удобно для ежедневной разработки и экспериментов.
- `go build <file.go>` — полноценная компиляция и создание бинарного исполняемого файла (`.exe`) рядом с кодом.
- `go test ./...` — запуск всех тестов в проекте.
