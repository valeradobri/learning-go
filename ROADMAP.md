- **Режим:** 2 рабочих дня / 2 выходных
- **Занятия:** только в выходные дни

### Стиль подачи материала

1. **Интерактивный учебник, не лекция.** Материал подаётся дробно — небольшими блоками. После каждого блока задаётся вопрос или мини-задание. Следующий блок — только после ответа Валеры.

4. **notes.md пишется совместно** — в конце урока ассистент предлагает готовый конспект для `notes.md` в папке текущего дня.

## ✅ Пройденные темы

### Урок 01 — Переменные и типы данных

- **Папка:** `lessons/lesson01-variables/`
- **Статус:** ✅ Завершён
- **Что изучено:**
  - Объявление переменных: `var x int`, `:=` (короткое объявление)
  - Базовые типы: `int`, `float64`, `string`, `bool`
  - Вывод: `fmt.Println`, `fmt.Printf` с форматированием (`%d`, `%s`, `%f`, `%v`)
  - Константы: `const`
  - Нулевые значения типов (zero values)

### Урок 02 — Управляющие конструкции

- **Папка:** `lessons/lesson02-control-flow/`
- **Статус:** ✅ Завершён
- **Что изучено:**
  - `if / else if / else` — правило: `else` на одной строке с `}`
  - Логические операторы: `&&`, `||`, `!`
  - `switch / case / default` — в Go автоматический `break` (нет fallthrough по умолчанию)
  - `for` — единственный цикл (бесконечный, с условием, `break`, `continue`)
  - `fmt.Scan(&var)` — ввод с клавиатуры; `&` — передача указателя (адреса памяти)
- **Практика:** Написан консольный банкомат (баланс, пополнение, снятие, защита от отрицательного ввода)

## 🔜 Запланированные темы

### Урок 03 — Массивы и слайсы
- **Статус:** ⏳ Следующий урок
- **Темы:**
  - `array` — фиксированный размер: `[5]int{1, 2, 3, 4, 5}`
  - `slice` — динамический массив: `[]int{}`
  - `append(slice, element)` — добавление элементов
  - Срезы диапазонов: `slice[start:end]`
  - `for range` — итерация по коллекциям

### Урок 04 — Функции
- **Статус:** 🔒 Не начат
- **Темы:**
  - Объявление функций: `func name(params) returnType`
  - Множественный возврат значений (особенность Go)
  - Именованные возвращаемые значения
  - `defer` — отложенное выполнение

### Урок 05 — Указатели (Pointers)
- **Статус:** 🔒 Не начат
- **Темы:**
  - `*T` — тип указателя, `&var` — взятие адреса, `*ptr` — разыменование
  - Передача по значению vs. по указателю

### Урок 06 — Структуры (Structs)
- **Статус:** 🔒 Не начат
- **Темы:**
  - Объявление `struct`
  - Методы на структурах (`func (s MyStruct) Method()`)
  - Receiver по значению и по указателю

### Урок 07 — Интерфейсы (Interfaces)
- **Статус:** 🔒 Не начат
- **Темы:**
  - Объявление интерфейса
  - Неявная реализация
  - `interface{}` / `any`

### Урок 08 — Обработка ошибок
- **Статус:** 🔒 Не начат
- **Темы:**
  - Идиома `error` как возвращаемое значение
  - `errors.New`, `fmt.Errorf`
  - Паника (`panic`) и восстановление (`recover`)

### Урок 09 — Горутины и каналы (Concurrency)
- **Статус:** 🔒 Не начат
- **Темы:**
  - `go func()` — запуск горутины
  - `chan` — каналы для коммуникации
  - `select`

### Урок 10 — Пакеты, модули, файлы
- **Статус:** 🔒 Не начат
- **Темы:**
  - Организация кода в пакеты
  - `go.mod`, `go get`
  - Чтение/запись файлов (`os`, `bufio`)
