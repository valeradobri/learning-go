# День 02: Управляющие конструкции (if-else, switch, for), ввод данных и банкомат

---

## 1. 📖 Подробный теоретический конспект

### 1.1. Ветвление `if - else if - else`
* **1.1.1. Принцип работы («Если — Иначе Если — Иначе»):**
  * Проверка условий выполняется строго сверху вниз.
  * Выполняется блок кода **только первой сработавшей ветки** (`true`), после чего программа немедленно выходит из всей цепочки проверок.
* **1.1.2. Синтаксические правила Go:**
  * Вокруг условий **НЕ ставятся круглые скобки** (писать `if (x > 0)` — неидиоматично, правильно `if x > 0`).
  * Фигурные скобки `{}` обязательны всегда, даже если внутри всего одна строчка кода.
  * **Критическое правило переноса строк:** слово `else` или `else if` **ОБЯЗАНО находиться на одной строке с закрывающей фигурной скобкой `}`**:
    ```go
    // ПРАВИЛЬНО:
    if a > 0 {
        ...
    } else {
        ...
    }

    // ОШИБКА КОМПИЛЯТОРА:
    if a > 0 {
        ...
    }
    else { // Go автоматически поставит ';' после '}' и выбросит синтаксическую ошибку!
        ...
    }
    ```

---

### 1.2. Логические операторы
* **`&&` (Логическое «И»):** истинно только тогда, когда **оба** условия верны.
  * Пример: `amount > 0 && amount <= balance` (сумма положительная И денег хватает на счете).
* **`||` (Логическое «ИЛИ»):** истинно, если хотя бы **одно** из условий верно.
  * Пример: `age < 0 || age > 120` (возраст меньше нуля ИЛИ больше 120).
* **`!` (Логическое «НЕ» / Отрицание):** переворачивает логическое значение с `true` на `false` и наоборот.

---

### 1.3. Оператор выбора `switch - case`
* **1.3.1. Ментальная модель:**
  * `switch` — это тумблер (на какую переменную смотрим).
  * `case` — положение тумблера («в случае, если значение равно...»).
  * `default` — положение по умолчанию (если ни один `case` не совпал).
* **1.3.2. Главное отличие Go от других языков:**
  * В Go **`break` ставится автоматически**! Проваливания в следующий `case` не происходит.
* **1.3.3. Перечисление условий:**
  * Можно указывать несколько значений через запятую:
    ```go
    case "зеленый", "green":
        fmt.Println("Поехали!")
    ```

---

### 1.4. Циклы: Единственный цикл `for`
В Go намеренно нет ключевых слов `while` и `do-while`. Все сценарии циклов покрывает `for`:
* **1.4.1. Бесконечный цикл:**
  * Используется в серверных приложениях, играх и терминалах для постоянного ожидания команд:
    ```go
    for {
        // Выполняется бесконечно
        if exitCondition {
            break // Принудительный выход из цикла
        }
    }
    ```
* **1.4.2. Управление выполнением:**
  * `break` — немедленно разорвать цикл и выйти наружу.
  * `continue` — пропустить остаток текущего шага и сразу перейти к следующей итерации.

---

### 1.5. Ввод данных с клавиатуры (`fmt.Scan`)
* **Синтаксис:** `fmt.Scan(&variable)`
* **Зачем нужен амперсанд `&`:**
  * Символ `&` передает **указатель** (точный адрес ячейки в оперативной памяти).
  * Функция `Scan` идет по этому адресу и записывает введенные пользователем данные прямо в память переменной.

## 3. ⚠️ Ошибки, грабли и выводы дня (Gotchas)
- **Ошибка 1: `syntax error: unexpected keyword else, expected }`**
  * *Причина:* Перенос слова `else` на новую строчку после `}`.
  * *Вывод:* В Go компилятор вставляет невидимые `;` на концах строк. Конструкция `} else {` пишется строго на одной строке!
- **Ошибка 2: `undefined: зеленый`**
  * *Причина:* Забыли кавычки в `case зеленый:`. Go посчитал это необъявленной переменной.
  * *Вывод:* Имена переменных пишутся без кавычек, а текст/строки — всегда в двойных кавычках: `case "зеленый":`.
- **Ошибка 3: `syntax error: unexpected {, expected expression`**
  * *Причина:* Недописанное условие сравнения `if amount > {`.
  * *Вывод:* После операторов сравнения (`>`, `<`, `==`) всегда должно стоять то, с чем сравниваем.
