# День 01: Основы Go, переменные, типы данных и константы

## 1. 📖 Подробный теоретический конспект

### 1.1. Анатомия и философия программы на Go
* **1.1.1. Философия создания языка:**
  * Разработан в Google (Роб Пайк, Кен Томпсон, Роберт Гризмер).
  * Главные цели: простота, отсутствие скрытой магии, надежность, сверхбыстрая компиляция и читаемость.
  * В Go всего 25 ключевых слов. Нет классов, классического наследования, исключений (`try/catch`) и перегрузки операторов.

* **1.1.2. Пакетная модель (`package`):**
  * Любой файл в Go начинается с указания пакета: `package <имя>`.
  * `package main` — специальный пакет, указывающий компилятору, что это **исполняемая программа** (а не подключаемая библиотека).
  * Внутри `package main` обязательно должна быть функция `func main()`.

* **1.1.3. Подключение библиотек (`import`):**
  * `import "fmt"` — стандартный пакет форматирования и ввода/вывода (Format).
  * Расширение Go в VS Code автоматически добавляет нужный импорт при первом использовании и удаляет его при сохранении файла, если он не используется.

* **1.1.4. Главная точка входа (`func main`):**
  * `func main() { ... }` — функция, с которой операционная система начинает выполнение программы.
  * В круглых скобках `()` у `main` ничего не указывается.
  * Весь исполняемый код, переменные и вызовы функций пишутся **внутри фигурных скобок `{ ... }`**.

* **1.1.5. Базовые команды терминала:**
  * `go run main.go` — скомпилировать программу в оперативную память и сразу запустить.
  * `go build main.go` — собрать готовый бинарный исполняемый файл (`.exe` на Windows).

### 1.2. Переменные: объявление и инициализация
* **1.2.1. Классическое объявление через `var` с типом:**
  * Синтаксис: `var <имя> <тип> = <значение>`
  * Пример: `var age int = 24`

* **1.2.2. Автовывод типа (Type Inference):**
  * Синтаксис: `var <имя> = <значение>`
  * Пример: `var salary = 2500.50` (компилятор сам назначит тип `float64`).

* **1.2.3. Краткое объявление через `:=` (Walrus-оператор):**
  * Синтаксис: `<имя> := <значение>`
  * Пример: `name := "Valeriy"`
  * **Главные правила `:=`:**
    1. Работает **ТОЛЬКО внутри тела функций**.
    2. Одновременно объявляет новую переменную и присваивает ей значение.

* **1.2.4. Блочное групповое объявление `var (...)`:**
  * Удобно для объявления нескольких связанных переменных:
    ```go
    var (
        host = "localhost"
        port = 8080
    )
    ```

---

### 1.3. Значения по умолчанию (Zero Values)
* **1.3.1. Концепция безопасной памяти:**
  * В Go переменные никогда не содержат "случайный мусор" из памяти.
  * Если переменная создана без начального значения, ей присваивается Zero Value:
    * Числовые типы (`int`, `float64`): `0` или `0.0`
    * Строки (`string`): `""` (пустая строка)
    * Булев тип (`bool`): `false`
    * Указатели, срезы, интерфейсы: `nil`

---

### 1.4. Базовые типы данных в деталях
* **1.4.1. Целые числа (Integers):**
  * `int`: стандартный целочисленный тип (на 64-битной Windows равен 64 бит).
  * `int8`, `int16`, `int32`, `int64` — типы с фиксированным размером.
  * `uint8` (синоним `byte`) — беззнаковое целое от 0 до 255.

* **1.4.2. Дробные числа (Floats):**
  * `float64`: стандартный тип для чисел с плавающей точкой (двойная точность).
  * `float32`: одинарная точность.

* **1.4.3. Булев тип (Booleans):**
  * `bool`: принимает только `true` или `false`.
  * В Go нет неявного приведения `0/1` к `bool`.

* **1.4.4. Строки (Strings):**
  * `string`: неизменяемая последовательность байт в кодировке UTF-8.

---

### 1.5. Строгая типизация и преобразование типов (Type Casting)
* **1.5.1. Принцип абсолютной строгости:**
  * В Go отсутствует автоматическое неявное приведение типов.
  * Нельзя напрямую сложить или перемножить `int` и `float64`.

* **1.5.2. Явное преобразование:**
  * Синтаксис: `Тип(значение)`
  * Пример:
    ```go
    var price int = 100
    var tax float64 = 1.20
    total := float64(price) * tax // 120
    ```

* **1.5.3. Нетипизированные константы (Untyped Constants):**
  * Числовые литералы (например, `9.0`, `32`) могут временно подстраиваться под тип соседней переменной, если при этом не теряется дробная часть.

---

### 1.6. Константы (`const`)
* Объявляются через ключевое слово `const`.
* Значение константы должно быть известно на этапе компиляции.
* Константу невозможно изменить во время работы программы.
* Пример:
  ```go
  const OS = "windows"
  ```

---

### 1.7. Пустой идентификатор `_` (Blank Identifier)
* **Политика чистоты кода:** компилятор Go запрещает оставлять объявленные, но неиспользованные локальные переменные (`declared and not used`).
* Чтобы временно заглушить ошибку неиспользуемой переменной, используется `_`:
  ```go
  secretCode := 12345
  _ = secretCode
  ```

## 3. ⚠️ Ошибки, грабли и выводы дня (Gotchas)
- **Ошибка 1: Автоудаление `import "fmt"` при сохранении в VS Code.**
  * *Причина:* Инструмент `goimports` удаляет библиотеки, если функции из них еще не вызваны в коде.
  * *Вывод:* Сначала пишем вызов (например, `fmt.Println`), затем сохраняем (`Ctrl + S`).
- **Ошибка 2: `syntax error: unexpected := in parameter list`.**
  * *Причина:* Переменные были случайно записаны в круглые скобки `func main(...)`, а не внутрь тела `{ ... }`.
  * *Вывод:* У `func main()` круглые скобки всегда пустые. Весь исполняемый код пишется строго внутри фигурных скобок `{ }`.
- **Ошибка 3: `invalid operation: price * tax (mismatched types int and float64)`.**
  * *Причина:* Попытка выполнить математическую операцию над переменными разных типов.
  * *Вывод:* Всегда явно приводить типы вручную: `float64(price) * tax`.
- **Ошибка 4: `declared and not used: secretCode`.**
  * *Причина:* Локальная переменная создана, но нигде не прочитана.
  * *Вывод:* Использовать переменную или временно заглушить через `_ = secretCode`.

## 5. 📝 Итоги первого дня
- **Ощущения от языка:** Go очень строгий, но честный. Компилятор сразу бьет по рукам за любые неточности (типы, лишние переменные, скобки), предотвращая скрытые баги.
