# 🚀 Learning Go

Персональный репозиторий для последовательного и глубокого изучения языка программирования **Go (Golang)** с абсолютного нуля до уровня **Junior Go Developer** и самостоятельной разработки надежных backend-приложений.

---

## 🎯 Цели обучения

1. Освоить фундаментальные принципы и философию языка Go.
2. Научиться писать чистый, производительный и идиоматичный код (*Idiomatic Go*).
3. Понять внутреннее устройство языка: компиляцию, типизацию, работу с памятью и планировщик горутин.
4. Освоить backend-стек: HTTP-серверы, REST API, маршрутизацию, работу с PostgreSQL, Docker и тесты.
5. Создать портфолио из нескольких полноценных проектов для выхода на позицию Junior Backend Developer.

## 🧠 Принципы обучения

- **С абсолютного нуля:** никаких скрытых допущений о наличии глубоких предварительных знаний.
- **Простота и глубина:** сначала простое объяснение на жизненных аналогиях, затем строгое техническое определение.
- **Малые логические блоки:** не перегружать занятия, один урок — одна законченная тема.
- **Формула урока:** Теория ➡️ Разбор кода ➡️ Подводные камни ➡️ Самостоятельная практика ➡️ Проверка знаний.
- **Понимание «почему»:** объяснение внутренних механизмов рантайма и компилятора, а не просто заучивание синтаксиса.
- **Подводные камни:** разбор типичных ошибок новичков и неочевидного поведения языка.
- **Идиоматичный Go:** следование принятым соглашениям сообщества (Effective Go).
- **Честный Code Review:** ментор не переписывает код за студента, а указывает на проблемы, уязвимости и пути улучшения.
- **Никакой спешки:** переход к следующей теме происходит только после уверенного усвоения текущей.
- **Регулярное повторение:** интервальный возврат к пройденным темам для закрепления.

## ⏱️ Учебный график

- **Формат работы:** 2 рабочих дня / 2 выходных дня.
- **Время занятий:** с 10:00 до 13:00 (2–3 часа) в каждый выходной день.
- **Схема:**
  - *Выходной день 1:* изучение теории, разбор демонстрационных примеров, концептуальные вопросы.
  - *Выходной день 2:* самостоятельное написание кода, решение задач, Code Review и работа над ошибками.
  - *Рабочие дни:* полноценный отдых или необязательный легкий просмотр конспекта в [docs/NOTES.md](docs/NOTES.md).
